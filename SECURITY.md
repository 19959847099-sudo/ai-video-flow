# Security policy

AI Video Flow is currently a release candidate. Please report a credible vulnerability, exposed credential, unsafe project/media-file handling, or dependency issue privately.

Report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/19959847099-sudo/ai-video-flow/security/advisories/new) for this repository. That form is enabled and creates a private security advisory visible only to you and the maintainers. Do not place exploit details, keys, private project files, or customer data in a public issue. The policy view is at [security/policy](https://github.com/19959847099-sudo/ai-video-flow/security/policy).

For a report, include the affected version, Windows version, a minimal reproduction using synthetic data, impact, and any safe logs. Remove tokens, local paths, and personal material. The project does not promise a fixed response time at RC1.
