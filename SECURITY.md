# Security policy

AI Video Flow is currently a release candidate. Please report a credible vulnerability, exposed credential, unsafe project/media-file handling, or dependency issue privately.

There is no public repository or private security-reporting channel configured yet. **Before publication**, the maintainer should enable GitHub private vulnerability reporting and update this page with the real reporting route. Do not place exploit details, keys, private project files, or customer data in a public issue. Until a private route exists, retain the report locally and request a secure contact channel from the repository maintainer before sharing details.

For a report, include the affected version, Windows version, a minimal reproduction using synthetic data, impact, and any safe logs. Remove tokens, local paths, and personal material. The project does not promise a fixed response time at RC1.
