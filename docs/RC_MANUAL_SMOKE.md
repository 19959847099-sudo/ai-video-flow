# V0.1 Windows portable manual smoke

1. Extract the archive to a normal user-writable folder.
2. Start AIGCFlow.exe. Confirm that no console window appears.
3. Create or open a project whose path contains Chinese text and spaces.
4. Apply a Production Script, then enter Preparation, Production, Creative and Assembly.
5. Open Settings and confirm FFmpeg, FFprobe, OTIO and version information.
6. Close in Production, restart, and confirm project/workspace context returns.
7. Temporarily rename runtime/ffmpeg/bin and confirm startup still works while media actions fail locally.
8. Confirm the application exits and no AIGCFlow or FFmpeg process remains.

Do not use a production project for RC smoke. Commercial provider calls must remain zero.
