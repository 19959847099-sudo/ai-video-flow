# AI Video Flow v0.1.0-rc.1 — release draft

This is the first Windows release candidate. It is **not published yet**. When approved, create tag `v0.1.0-rc.1`, title the GitHub release **AI Video Flow v0.1.0-rc.1**, mark it as a **pre-release**, and attach the three files below. Complete the [public release audit](../PUBLIC_RELEASE_AUDIT_V0.1.md) before doing so.

## Highlights

- A D-layout desktop workflow links Preparation, Production, Creative, and Assembly.
- Structured scripts produce shared asset requirements. Production retains generated/imported Candidates and review history; a Current take is selected explicitly.
- Creative revisions are Proposal/Diff/Human Draft until the user explicitly applies a valid change. Assembly consumes Current media for editing, preview/output, and OpenTimelineIO handoff.
- Windows per-user Installer and portable ZIP are built from the same application version. Uninstalling the Installer removes the program, not user projects.

## Current limits

This is an RC, not a stable migration format. Make a backup before opening important projects; cross-version project migration is not yet defined. The default image, audio, and video providers use local zero-call fixtures, **not** commercial model APIs. Creative text can optionally use a configured OpenAI-compatible API. The Windows builds are unsigned and may show a SmartScreen warning. There is no automatic updater or credential store.

Local automated gates cover the full regression suite, clean portable extraction, Installer first launch, project reopen, same-version reinstall, uninstall preservation, and reinstall. They do not replace interactive wizard review or live commercial-provider validation. See [Releasing](../RELEASING.md) and the [Installer evidence](../../evidence/V0.1-Windows-Installer/README.md).
