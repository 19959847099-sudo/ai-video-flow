## GUI

可创建 / 编辑角色，导入 / 预览 / 删除 Reference 关联，设置身份图，创建 / 编辑 Look 并选择专用图；创建、查看、编辑 Shot，选择角色与对应 Look，保存并生成测试任务。任务成功在界面明确显示。普通使用无需手改 JSON 或理解内部 ID。

## 数据结构

| 对象 | 落地方式 |
|---|---|
| Character | 独立 JSON；稳定 ID、名称、描述、核心身份、Reference 与 Look 集合 |
| Look | 角色内独立 ID、名称、状态描述、外观补充、reference_ids |
| Reference | 项目内图片；按内容 SHA-256 去重，保存相对 data/ 的路径；身份参考关系单独保存 |
| Shot | 独立 JSON；character_id + look_id，以及镜头需求、生成描述 |
| Generation Task | 当次 Shot / Character / Look 快照、有效参考图、分项 prompt_source；不含 Provider 字段 |
| Provider Adapter | 一个 prepare 协议；Dummy 检查媒体并输出独立模拟请求，明确 api_called=false |

有效参考图 = 身份图与当前 Look 图的去重并集。原始导入路径不进入核心资产关系。JSON 使用 UTF-8 和原子替换。移除 Reference 关联不删除历史任务可能使用的图片。
