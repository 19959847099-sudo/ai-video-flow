## Scene Pack

Scene 是独立 JSON，保存稳定 ID、名称、描述、稳定视觉 / 空间特征、Reference 集合、稳定参考图关联与 State 集合。State 保存独立 ID、名称、描述、环境变化和专用参考图。

GUI 可新建、编辑场景与状态，导入、预览、移除图片关联。图片导入、哈希去重和相对路径复用 A-01 Store，没有第二套文件管理系统或万能资产模型。

## Shot / Generation Task

新 Shot 以稳定 ID 引用 Character、Look、Scene、Scene State。旧 0.1 数据兼容读取，新双资产 Shot / Task 使用 0.2。

任务包含四类对象快照、角色有效参考图、场景有效参考图、分项 prompt_source 与最终 final_prompt。分别取身份 / 稳定图与当前 Look / State 专用图，不混入其他状态专用图。核心任务不含 Provider 字段，旧 prepare 边界保持可用。

## Mock Provider

submit 返回持久化执行 ID，GUI 后台轮询经历 pending → processing → completed；失败保留 failed 与错误。处理中断后可在下次启动恢复。每次执行保存 Task ID、Shot ID、Take 编号、Provider / Model、结果与必要 Retry 来源。

本机 FFmpeg 编码 3 秒、640×360、H.264 MP4 占位视频，明确显示 MOCK、Shot、角色、场景和 Take。无网络调用、无 API 密钥、无付费服务。

## Result / Review / Retry / Selected

完成后先验证媒体，再复制至按执行 ID 确定的结果目录，保存 result.json、video.mp4 和从视频提取的 poster.png。GUI 自动找到对应 Shot 的结果，用 FFplay 播放真实视频。

Review 使用每个 Shot 独立的 selected_result_id 和 Reject 原因。Retry 创建新的执行与任务；可选生成描述只作用于该新任务，不覆盖 Shot 默认描述。Selected 可恢复对应 Result、Execution、Task、最终 Prompt、角色 / Look 与场景 / State。
