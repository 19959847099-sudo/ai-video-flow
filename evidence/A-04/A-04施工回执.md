## Provider Dry Run

DSH 经 Python bridge 调用原 fal/Kling O3 Standard Reference-to-Video Fixture 路线，保存原 Request / Response 证据，经历 pending → processing → completed。没有 HTTP Transport、密钥读取或线上兜底。

生成的是 FFmpeg 测试视频；Task、Result、最终 Provider 描述可追溯，不是 Kling 实际生成画面。

## 遗留 / 风险

DSH 为预发行版本，后续升级需重新验证 profile、工具与退出契约。完整官方 npm 发行版有约 213 MiB / 518 包安装成本，作为可移除外部运行时隔离保存；未扩展其其他子系统。

当前文件存储按单写入者使用，GUI 与 Harness 不应并发修改同一 data。新机器需安装便携 Node、锁定 npm 依赖及 FFmpeg。执行证据中的绝对路径仅用于本机审计，核心媒体仍用相对路径。

## 当前真实能力

项目能维护角色和场景双核心资产，生成独立任务快照，经原 GUI 或官方 DSH 触发零调用视频生产，自动回收真实媒体并追溯生成上下文。DSH 可以调用媒体探测工具；停止 DSH 后原 GUI 仍可播放和人工审核。新增候选保持未选择。
