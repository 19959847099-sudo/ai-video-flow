# V0.2 第一轮施工回执

日期：2026-09-17。任务：**剧本驱动准备闭环 + 章节工作区视觉母版**。

## 结果

本轮已完成实现与自检，等待用户验收。正式入口 `start.cmd` 已切换到 Qt 准备工作区。

当前真实主链：规范剧本 → 确定性解析 → 章节/镜头/资产需求 → 文件扫描 → 缺失/歧义/变更 → 导入或明确选择 → 章节 Ready → 保存重开。

- 新建独立的 V0.2 模型，不把多人物等语义塞回旧单人物 Shot。
- 支持影片、章节、镜头、多人物、`/` / `-` / `【】`、完整视觉、独立 Voice、环境与背景音、关键物件、视频参照、自然语言创作区。
- 同名多候选明确进入待确认；改名仅在一对一内容匹配时恢复身份；替换保留旧版本并等待用户确认。
- 历史引用保留剧本版本、资产版本和使用镜头；变更可回到当前剧本位置，已移出的镜头仍保留历史提示。
- 草稿自动保存；错误带源行；无效草稿不覆盖有效生产需求。恢复项目、章节、镜头、编辑位置及映射状态。
- 界面是真实数据驱动的章节准备工作区，包括图像缩略预览、媒体播放入口、参照选择、导入、文件夹打开和规则帮助。

## Scope / Done

Scope 与用户批准一致：准备闭环和视觉母版。未接入新生成、红黄绿候选、轻剪或章节输出功能；旧媒体执行器未重构，旧数据未迁移。

Done 自检：**已完成**。视觉母版采用石墨侧栏、暖白文本画布与统一参照卡片；实际检查正常和紧凑窗口，不以控件可点击代替视觉验收。最终视觉与阶段收口由用户裁决。

## 保留边界

- 同步在打开项目或手动触发时执行，不是实时文件监视器。
- Voice 本轮支持参考音频文件；Provider Voice ID 绑定由后续音声生产轮接入。
- 编号是结构身份，改编号视为新镜头；不猜测重编号迁移。
- 备份必须整体包含项目目录与 `.history`。单应用窗口写入，外部可编辑素材文件。
- 生成、候选红黄绿、轻剪与输出不在本轮 Done。Ready 不等于生成或审美通过。
