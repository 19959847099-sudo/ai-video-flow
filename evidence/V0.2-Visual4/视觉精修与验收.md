# V0.2 准备工作区 · 减法精修验收

本轮沿用蓝黑视觉方向与三栏信息架构，只调整呈现层。Parser、Asset Requirement / Mapping、文件同步、保存恢复和生产状态语义保持不变。

## 减掉的内容

- 撤去顶栏、侧栏、Script、Assets、Preview 和单条资产上的非必要描边；保留筛选框、主要操作及必要焦点边界。
- 移除重复的影片名、工作阶段标签、Script 副标题、Monitor 类型条、参照说明、进度条和剧本底部提示；摘要收为一行。
- 已就绪资产只显示低调色点；映射动作改为无框次级按钮，源行入口缩成行号。左侧非当前 Shot 降低亮度，当前 Shot 保留明确选择面。
- Script Canvas 略亮于工作区；当前行高亮、行号更轻，Shot 编号更明确，方括号参照使用低对比色底作为生产 Token。自然语言保持正常文本阅读。
- 深蓝黑渐变、弱网格、顶部环境光、品牌标记和真实媒体监看保持原方向。
