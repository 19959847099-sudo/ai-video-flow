# V0.2 产品语言与信息密度收口

起点：`02a106b`。本轮保留 C「镜头上下文」视觉骨架及既有生产状态、审核与绑定规则，只调整用户可见措辞、状态呈现和少量重复控件。

- 准备页去掉重复的阶段、工程说明和同步提示；缺失、变更、歧义仍有明确状态与处理入口。
- 候选页保留三枚纯颜色审核圆点，缩短选用、导入与历史版本文案；隐藏普通视图中的路径、校验值和时间戳。
- 提示词页保留编辑、保存、失效提示与覆盖确认；新草稿的正文改用中文短句，正式参照路径仍保留在草稿内容中，以维持已验证的参考事实契约。已有草稿不会被自动改写。
- 轻剪页用“裁切、切分、预览、导出成片、交给专业剪辑”表达操作；阻塞与失败消息在界面边界转为可行动的短句，并去重。
- 未配置生成服务使用简短、真实的状态提示；示例媒体自带的真实性水印保持原样。

验证：13 项聚焦 Qt/Prompt 测试通过；真实 Qt 标准与紧凑窗口已检查。隔离项目中实际走通候选设为当前、提示词创建/保存、文件变更与失效、非法裁切、无选定视频、预览、成片导出及专业剪辑交接。未运行无关的大规模历史回归。

截图：`before-*.png` 与同名 `after-*.png` 对照四个主页面；`after-preparation-compact.png`、`after-finishing-compact.png` 是紧凑窗口；其余 `after-*.png` 记录真实媒体、异常状态和输出。最终提交号见本轮回执。

仍可在后续独立轮次检查旧项目中已保存的人工提示词措辞；本轮没有自动覆盖用户文本。
